What "upscale" actually does here: it increases pixel count using a stepped high-quality resample (better than a single stretch) and writes a real 300 DPI tag into the file so print tools read it correctly. It does not invent new detail the camera didn't capture — for that you'd need a dedicated super-resolution model. Themes are genuine color/light processing, not a generative re-draw.
Everything happens in-browser via Canvas — your photo is never sent anywhere. See README.md in this repo for how to add your own themes.
